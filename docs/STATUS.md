## Модели контура

Подобраны замером `poh-issue-agents/scripts/model_probe.py` по всем десяти
моделям аккаунта (2026-09-09). Правило выбора — самая дешёвая по выходным
токенам из тех, что держат схему и ветвление; ничьи разрешаются скоростью.

| Переменная | Значение | Где |
|---|---|---|
| `MODEL_GATE`, `MODEL_CLASSIFY` | `glm-5.2` | `worker/llm.py` |
| `ANTHROPIC_MODEL` (путь `claude -p`) | `glm-5.2` | compose |
| `BFT_DIRECT_MODEL` | `glm-5.2` | compose; инертна, пока `BFT_DIRECT_STAGES` пуста |
| `DEVELOP_MODEL` | `openai/glm-4.6` | compose |
| `PR_AGENT_MODEL` | `openai/glm-4.6` | ревьюер |

`DEVELOP_MODEL` не менялся намеренно: замер проверял разбор текста по схеме, а не
написание кода. Мерить его следует живым прогоном разработки, не пробой.

`glm-5.3` из конфигов убрана: она оказалась самой прожорливой из десяти (3066
выходных токенов против 1875 у `glm-5.2`) и работала на `claude -p` невыбранной,
потому что `ANTHROPIC_MODEL` не была задана и модель выбирал провайдер.
